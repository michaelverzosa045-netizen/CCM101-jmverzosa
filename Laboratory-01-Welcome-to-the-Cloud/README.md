# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity helped me understand how to use a cloud-based Linux environment through KillerCoda Playground. I learned basic Linux commands and how to check important system information. I also practiced creating, organizing, and managing files and folders using the terminal. The activity helped me become more familiar with GitHub and how it can be used to create a Cloud Computing portfolio. Overall, this experience improved my practical skills and gave me a better understanding of cloud computing and Linux.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I accessed the Ubuntu Linux environment using KillerCoda and created a new Linux user account. I successfully logged in to the new account and checked basic information such as my username, working directory, and hostname. I also learned how to view details about the Linux distribution, kernel, CPU, memory, and disk space. I practiced creating directories and a Markdown file for my Cloud Computing portfolio. This activity helped me improve my Linux skills and understand how these tools are used in cloud computing.

## Linux Commands Used

- sudo adduser – Created a new Linux user.
- sudo usermod -aG sudo – Added the user to the sudo group.
- su - – Logged in to the new user account.
- whoami – Displayed the current username.
- pwd – Displayed the current working directory.
- hostname – Displayed the hostname.
- cat /etc/os-release – Displayed Linux distribution information.
- uname -r – Displayed the kernel version.
- lscpu – Displayed CPU information.
- free -h – Displayed memory information.
- df -h – Displayed available disk space.
- mkdir – Created directories.
- cat – Displayed the contents of a file.
